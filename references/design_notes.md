# ملاحظات تصميم قالب الـ PDF

القالب في `assets/template.html` جاهز فيه كل الـ CSS، انسخه وابدأ منه، وامسح المحتوى المثال واحط بدله محتواك.

## الكلاسات المتاحة

| الكلاس | الاستخدام |
|---|---|
| `<h1>` | عنوان الملف الرئيسي (فيه مكان تحطه لينك المصدر جواه `<span class="source-link">`) |
| `<h2>` | عنوان قسم رئيسي |
| `<h3>` | عنوان فرعي |
| `<div class="point">` | فقرة/نقطة مترجمة من المحتوى الأصلي |
| `<div class="explain-box">` مع `<span class="label">💡 يعني إيه؟</span>` | شرح وتبسيط للنقطة اللي قبلها مباشرة |
| `<div class="practical-box">` مع `<span class="label">🛠️ تطبيق عملي</span>` | مثال/سيناريو تطبيقي للنقاط العملية |
| `<div class="term-box">` مع `<span class="label">📌 مصطلح</span>` | تعريف مصطلح تقني مهم لو احتجت توضيح إضافي |
| `<pre class="code-block"><code>...</code></pre>` | كتلة كود كاملة — تفضل LTR تلقائيًا حتى في صفحة RTL |
| `<code class="inline">...</code>` | مصطلح تقني قصير جوه جملة عربية (زي `array`, `API`) — يفضل LTR |
| `<div class="cover-note">` | ملاحظة تعريفية أعلى الملف (اختياري) |

## قواعد مهمة

1. **الأكواد دايمًا جوه `code-block` أو `inline`** — متسيبش كود عادي بره الكلاسات دي، هيتكسر اتجاهه.
2. **كل `explain-box` أو `practical-box` لازم يجي مباشرة بعد الـ `point` بتاعه** — الترتيب ده اللي بيخلي الشرح "تحت النقطة على طول" زي ما الشخص طلب.
3. لو القسم طويل جدًا وفيه نقط كتير، ماينفعش تحط كل حاجة في `div.point` واحدة — قسمها لعدة `point` كل واحد بموضوعه، وتحت كل واحد الشرح بتاعه.
4. الألوان: أزرق (`explain-box`) للشرح العام، أخضر (`practical-box`) للتطبيق العملي، أصفر (`term-box`) للتعريفات — حافظ على التمييز ده عشان يبقى واضح بصريًا.
5. لو محتاج جدول، استخدم `<table>` العادي — فيه تنسيق جاهز في الـ CSS.

## قاعدة حرجة: عربي + رابط/مسار في نفس السطر = نص متكسر

لو حطيت كومنت فيه كلمات عربية + رابط أو مسار في نفس السطر جوه `code-block`، خوارزمية الـ bidi (حتى مع `unicode-bidi: isolate`) هتقلب ترتيب الكلمات والنص هيطلع مبعثر وغير مقروء. القاعدة: خليهم دايمًا في سطرين منفصلين — سطر عربي بحت، وسطر تاني للرابط/المسار بالإنجليزي بحت. لو مضطر تسيب السطر زي ما هو من غير ترجمة، خليه زي ما هو بالكامل بالإنجليزي.

## اختبار سريع للخط العربي

لو ظهرت مربعات فاضية بدل الحروف العربية في الـ PDF، شغل:
```bash
fc-list | grep -i amiri
```
لو مفيش نتيجة، رجع لخطوة "تجهيز البيئة" في SKILL.md وثبّت الخطوط تاني.
